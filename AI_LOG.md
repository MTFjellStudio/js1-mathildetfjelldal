## Scope of AI Assistance

AI was primarily used as a learning resource for understanding JavaScript, planning the assignment, explaining errors, debugging and reviewing code.

- **Learning:** ChatGPT explained JavaScript concepts, syntax and programming logic with small illustrative examples. NotebookLM was used for module summaries, quizzes and revision of course material.
- **Planning:** Brainstormed project structure, implementation stages, file organisation and user flows. Organised tasks and progress tracking in Notion.
- **Debugging and review:** Used ChatGPT to explain errors, review student-written code, identify potential problems and discuss possible improvements.
- **Testing and documentation:** Discussed test cases, reviewed assignment requirements and organised AI usage documentation.
