# Rainy Days – JavaScript 1 Course Assignment

![Rainy Days logo](images/rainy-days-logo/rainy-days-logo.png)

## Description

Rainy Days is an e-commerce website for outdoor jackets.

This project builds on my previous Rainy Days HTML and CSS project and is being developed as part of the JavaScript 1 course assignment at Noroff.

The purpose of the assignment is to convert the existing static e-commerce website into a dynamic application using vanilla JavaScript and the provided Rainy Days API.

## Project Goals

The completed application will:

- Fetch product data from the Rainy Days API
- Display products dynamically
- Display individual product pages
- Filter products by category or gender
- Allow products to be added to and removed from a shopping cart
- Store the cart between pages
- Display cart quantities and totals
- Provide a simulated checkout and confirmation flow
- Display loading and error states

## Built With

- HTML
- CSS
- Vanilla JavaScript

## Project Structure

The project contains separate pages for:

- Homepage
- Product categories
- Individual products
- Shopping cart
- Checkout
- Order confirmation
- About Rainy Days

JavaScript is organised into modules for API requests, products, cart functionality, checkout and shared UI behaviour.
